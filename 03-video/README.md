# 03 · Vídeo: Pautas, Roteiros, Edição e YouTube

Memória do **Departamento 3 (Vídeo)**.

| Subpasta | Conteúdo | Quem escreve |
|---|---|---|
| `planejamento/` | Pautas de vídeo longo e curto, calendários de gravação e publicação, séries | diretor-conteudo |
| `rascunhos/` | Roteiros técnicos de edição (A/V), shot lists de B-roll, specs de legenda dinâmica, pacotes 1-para-10 de multiplicação, pacotes de otimização para YouTube | editor-video, multiplicador-conteudo, gestor-youtube |
| `aprovados/` | Somente peças com veredito APROVADO do auditor-qualidade | **apenas** auditor-qualidade |

**Conteúdo-mãe:** transcrições e links de vídeos longos usados para multiplicação podem ser salvos em `planejamento/` com o tipo `transcricao` (ex.: `2026-11-23_live-precificacao_transcricao.md`).

**Nomenclatura:** `AAAA-MM-DD_<campanha-ou-video>_<tipo>_<descricao>[_vN].md`
